# Luckroute Meeting Notes / Сводка созвона

Приложение от Luckroute IT department для Windows и macOS превращает одну или несколько видео- и аудиозаписей в полную расшифровку и подробную деловую сводку. Видео: MP4, MOV, M4V, MKV, AVI, WebM. Аудио: MP3, WAV, M4A, AAC, FLAC, OGG, OPUS, WMA, AIFF/AIF, AMR. Если в записях несколько разных встреч, приложение может разделить их и создать отдельную пару TXT для каждого созвона. Интерфейс и результат переключаются между русским и английским языками.

## Как пользоваться

1. Установите приложение обычным установщиком операционной системы.
2. Выберите режим. «На компьютере» работает без API-ключа: один раз нажмите «Скачать модели» (около 3 ГБ, нужен интернет), затем обрабатывайте записи полностью без интернета. Чтобы разблокировать OpenAI, сохраните свой API-ключ в настройках.
3. Выберите RU или EN — язык интерфейса, сводки и имён итоговых файлов. Локальное распознавание автоматически определяет язык речи и не переводит исходную запись.
4. Выберите до 20 видео- и аудиофайлов. Форматы можно смешивать; файлы обрабатываются по порядку их названий.
5. Выберите папку для результата.
6. Имена и роли анализируются автоматически, отдельной галочки нет. OpenAI сопоставляет подписи видео и диалог. Локально явно названные люди и роли учитываются в сводке, но голоса пока не разделяются и отдельные реплики не подписываются именами.
7. Если внутри записи есть разные встречи, включите «В записях несколько разных созвонов».
8. Нажмите «Создать расшифровку и сводку».

Один созвон, разделённый на несколько видео, обрабатывается как единая последовательность. Граница файла сама по себе не считается началом новой встречи. Если программа уверенно находит несколько самостоятельных созвонов, для каждого сохраняются:

- \`… — созвон 01 — <название> — расшифровка.txt\`;
- \`… — созвон 01 — <название> — сводка.txt\`.

Если файл с таким именем уже существует, приложение создаёт вариант \`(2)\`, \`(3)\` и не перезаписывает прежний результат.

- повреждённый или пустой ответ повторно разбирается меньшими частями; при неудаче приложение сообщает об ошибке и сохраняет расшифровку вместо неполной сводки;
- ползунок «Краткая / Обычная / Подробная» работает в обоих режимах и запоминается;
- для 45–60 минут ориентиры составляют 1 000–3 000, 3 000–10 000 и 10 000–30 000 символов с пробелами; для других записей объём зависит от длительности и насыщенности;

В локальном режиме подробность регулирует количество дополнительных фактов; явно выделенные моделью решения, задачи и открытые вопросы сохраняются на всех уровнях. Проверка ссылок подтверждает наличие исходных строк, но не гарантирует безошибочную интерпретацию небольшой моделью. Неверно распознанные слова могут влиять на сводку.

### Требования и ограничения локального режима

Windows 10 версии 1903 или новее / Windows 11. Встроенные движки используют UTF-8 для поддержки русских и других не-ASCII путей без изменения системной локали.

Около 3 ГБ для моделей плюс место для приложения, временного WAV и результатов. Рекомендуется минимум 8 ГБ оперативной памяти, лучше 16 ГБ. Windows x64 и Intel Mac требуют процессор с AVX; Apple Silicon использует Metal с резервным переходом на CPU. Скорость сильно зависит от компьютера: длительная запись на старом ноутбуке может обрабатываться долго. Закрывайте приложения, занимающие много памяти.

Локальная модель меньше облачной: качество распознавания и сводки может быть ниже OpenAI. Голоса и имена по видео локально пока не распознаются: «Спикер» — общая метка, а не один человек. Имена в тексте сводки могут браться только из явно произнесённых фактов. Разделение встреч автоматическое, требует проверки; смена темы не должна считаться новой встречей. При ошибке разделения сохраняется одна общая пара TXT с предупреждением.

Первичная загрузка обращается к Hugging Face и его CDN только за весами моделей; видео, аудио и текст при этом не отправляются. После загрузки обработка использует только встроенные исполняемые файлы и локальные модели; не открывает сетевой сервер и не переключается на OpenAI при ошибке. Прерванная загрузка сохраняет файл `.part` и продолжается по следующему нажатию. Перед обработкой проверяются размеры и SHA-256 моделей.

## Формат сводки

Каждая сводка содержит:

- краткое резюме;
- обсуждение по темам;
- принятые решения;
- задачи по ответственным;
- открытые вопросы;
- итоги.

Объём пропорционален содержанию созвона. Личные разговоры, приветствия, повторы и проверки связи исключаются, если они не влияют на работу. Предложения не выдаются за принятые решения, а имена, сроки и ответственные не додумываются.

## Автоматическое определение участников

В OpenAI для каждой метки голоса из видео выбирается до пяти кадров около разных реплик. Имя принимается после повторного совпадения читаемой подписи с видимым индикатором говорящего. Распознавание лиц не используется. Для аудиофайлов кадры не извлекаются.

Дополнительно анализируется диалог: самопредставления, повторные обращения с ответами и описания собственной работы. Программа проверяет, что подтверждающие цитаты действительно есть в нужном фрагменте. Одиночное упоминание человека не считается идентификацией. Точная должность требует прямого утверждения участника; общая функция из контекста обозначается «предположительная роль». При противоречиях остаётся нейтральная метка. В TXT сохраняются источник подписи и цитаты для проверки. Идентификация вероятностная и может ошибаться; одинаковые буквенные метки в разных фрагментах не означают одного человека.

Локально отдельные голоса пока не разделяются. Имена и роли из явно произнесённого текста можно использовать в сводке, но не для уверенной подписи каждой реплики.

## Надёжность и восстановление

Аудио делится на 10-минутные фрагменты. После успешной расшифровки каждого фрагмента результат сохраняется в локальную контрольную точку. При повторном запуске с теми же файлами готовые части используются повторно. После полного успешного завершения контрольная точка удаляется.

Во время обработки приложение не даёт Windows или macOS приостановить задачу. Каждый сетевой запрос имеет ограничение по времени и до пяти попыток. Повторяются все временные HTTP 5xx, включая 520, а также ошибки соединения и ограничения частоты. Если всё же возникает ошибка, интерфейс предлагает открыть журнал диагностики без API-ключа.

Все полные расшифровки сохраняются до начала формирования сводок. Поэтому при сбое на позднем этапе уже готовый текст остаётся в выбранной папке.

## Конфиденциальность

В локальном режиме аудио, кадры и расшифровка не покидают компьютер. Сетевые обращения к OpenAI не выполняются даже при наличии сохранённого ключа. Функция определения имён по кадрам отключена. Удаление ключа автоматически выбирает локальный режим.

В режиме OpenAI приложение не отправляет видео целиком. Оно извлекает моно-аудио и отправляет фрагменты в OpenAI для распознавания, затем текст — для определения участников, разделения встреч и сводки. Для видео автоматически отправляется ограниченное число временных кадров, на которых могут быть видны участники и демонстрируемый экран. Этот режим следует выбирать только при разрешении на такую передачу данных.

Временное аудио и кадры удаляются после обработки даже при ошибке или отмене. Контрольные точки содержат распознанный текст и хранятся локально только до успешного завершения либо следующей попытки. Итоговые TXT сохраняются только в выбранную папку. Запросы сводки и анализа кадров выполняются с \`store: false\`.

API-ключ не зашит в приложение. Он шифруется системными средствами Electron: через защищённое хранилище Windows или связку ключей macOS.

## Готовые установщики

Защищённая ручная сборка релиза создаёт:

- \`Meeting-Notes-…-win-x64.exe\` — мастер установки Windows с выбором папки, ярлыком и запуском после установки;
- \`Meeting-Notes-…-mac-arm64.dmg\` — macOS для Apple Silicon;
- \`Meeting-Notes-…-mac-x64.dmg\` — macOS для Intel;
- общий ZIP с тремя установщиками и инструкцией;
- ZIP с исходным кодом релиза.

Каждый релиз содержит `SHA256SUMS.txt` для проверки целостности. Для файлов также создаются GitHub artifact attestations, а опубликованный релиз блокируется от последующей замены.

Сертификаты и нотариализация не используются. Windows-версия остаётся неподписанной, а macOS-версия получает проверяемую ad-hoc-подпись без сертификата.

### Первый запуск неподписанной версии

- **Windows:** если SmartScreen покажет «Система Windows защитила компьютер», нажмите «Подробнее», затем «Выполнить в любом случае».
- **macOS:** откройте подходящий DMG и перетащите приложение в \`Applications\`. При предупреждении о неизвестном разработчике запустите приложение через контекстное меню «Открыть». Терминал не нужен.

На корпоративных компьютерах системная политика может запретить обход предупреждения. В таком случае разрешение должен выдать администратор устройства.

## Разработка

Требуются Node.js 22+, npm, CMake и C/C++ компилятор (Visual Studio Build Tools на Windows, Xcode Command Line Tools на macOS). Это инструменты только для разработчиков, не для пользователей установщика. Перед упаковкой запустите `npm run build:local` на целевой ОС; команда собирает закреплённые версии whisper.cpp и llama.cpp.

\`\`\`bash
npm ci
npm run check
npm test
npm start
\`\`\`

Сборка выполняется на целевой ОС:

\`\`\`bash
npm run dist:win
npm run dist:mac
\`\`\`

Основные модели: \`gpt-4o-transcribe-diarize\` для расшифровки с разделением спикеров, \`gpt-5.4-mini\` для анализа кадров и \`gpt-5.6\` для подробной сводки и определения границ созвонов.
