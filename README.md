# Сводка созвона

Приложение для Windows и macOS превращает MP4-запись созвона в два локальных TXT-файла:

- `<имя видео> — расшифровка.txt` — полная расшифровка с таймкодами и метками спикеров;
- `<имя видео> — сводка.txt` — русская деловая сводка в согласованном формате.

## Как пользоваться

1. Установите приложение обычным установщиком операционной системы.
2. При первом запуске откройте настройки и один раз сохраните API-ключ OpenAI.
3. Выберите MP4 с записью созвона.
4. Выберите папку для двух TXT-файлов.
5. Нажмите «Создать расшифровку и сводку».

При повторном запуске ключ вводить не нужно. Если файл с таким именем уже существует, приложение создаст вариант `(2)`, `(3)` и не перезапишет прежний результат.

## Формат сводки

Для каждого созвона создаются разделы:

- краткое резюме;
- обсуждение по темам;
- принятые решения;
- задачи по ответственным;
- открытые вопросы;
- итоги.

Если внутри одной записи обнаружено несколько самостоятельных созвонов, они оформляются отдельно. Личные разговоры, приветствия, повторы и проверки связи исключаются, если они не влияют на работу. Имена, сроки и решения не додумываются.

## Конфиденциальность

Приложение не отправляет видеоряд. Оно локально извлекает из MP4 моно-аудио, делит его на 20-минутные фрагменты и отправляет эти фрагменты в OpenAI для распознавания. После обработки временное аудио удаляется. Итоговые TXT сохраняются только в выбранную пользователем папку.

API-ключ не зашит в приложение. Он шифруется системными средствами Electron: через защищённое хранилище Windows или связку ключей macOS.

## Готовые установщики

Автоматическая сборка создаёт:

- `Meeting-Notes-…-win-x64.exe` — мастер установки Windows с выбором папки, ярлыком и запуском после установки;
- `Meeting-Notes-…-mac-arm64.dmg` — macOS для Apple Silicon;
- `Meeting-Notes-…-mac-x64.dmg` — macOS для Intel.

Ручной запуск workflow **Build installers** сохраняет установщики как артефакты. Тег вида `v1.0.0` дополнительно публикует их в GitHub Releases.

Установщики намеренно собираются без сертификатов и нотариализации. Поэтому Windows SmartScreen или macOS Gatekeeper могут показать предупреждение. Установка всё равно выполняется через графический интерфейс операционной системы, без командной строки.

## Разработка

Требуются Node.js 22 и npm.

```bash
npm install
npm test
npm start
```

Сборка выполняется на целевой ОС, чтобы в приложение попал правильный бинарник FFmpeg:

```bash
npm run dist:win
npm run dist:mac
```

Основные модели: `gpt-4o-transcribe-diarize` для расшифровки с разделением спикеров и `gpt-5-mini` для структурированной сводки. Записи автоматически разбиваются так, чтобы каждый аудиофайл оставался значительно меньше лимита загрузки OpenAI в 25 МБ.
