# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются для последней опубликованной версии приложения.

## Как сообщить об уязвимости

Не создавайте публичный Issue, если сообщение содержит сведения об уязвимости, API-ключ, расшифровку, кадры созвона или журнал с конфиденциальными данными.

Используйте [приватное сообщение об уязвимости](https://github.com/luckrouteadmin/luckroute-meeting-notes/security/advisories/new). Укажите версию приложения, операционную систему, ожидаемое и фактическое поведение, а также минимальные шаги воспроизведения. Перед отправкой удалите реальные ключи и данные участников созвона.

Мы постараемся подтвердить получение сообщения в течение семи дней. Публиковать детали следует только после выпуска исправления или отдельного согласования.

## Проверка релиза

Для каждого нового релиза публикуется `SHA256SUMS.txt`. Установщики и архивы также получают GitHub artifact attestations. Опубликованные релизы не заменяются: исправление всегда выходит под новым номером версии.
